### T107. "Why does `$match {CONTRACT_ID: "123"}` return nothing, and how do you avoid it?"

**Strong answer:** `CONTRACT_ID` and `VERSION_NO` are stored as numbers in Mongo. `$match` equality is type-strict between string and number, so a String never matches. Oracle converted implicitly. Mongo never errors on a 0-row match, so the bug is silent (flags null, pages missing). Handlers convert with `safeNum`/`asNum` (`Long.parseLong`, fallback to the raw string if not numeric; Template12 `asNum` returns Integer when numeric). A `Long` filter equals a stored Int32 in numeric comparison, but a value stored as a string would not match. `Template12LandscapeDispatchHandler` does `Long.parseLong` and throws on non-numeric input.

**Weak answer:** "Mongo converts types."

**Red flags:** Never met the bug.

**Follow-up questions:**
- Where did it hurt in ASP? (T031.)
- Test? (`fetchServiceTaxInvoice_contractIdNonNumeric_keptAsStringInMatch`, `..._numericContractId_matchedAsLong`.)

### T108. "Why `$arrayElemAt` and not `$unwind` after a `$lookup`?"

**Strong answer:** To keep rows that have no match (left-join semantics). `$unwind` drops documents with an empty array unless `preserveNullAndEmptyArrays: true` (`AspDebitNoteHandler` uses that variant at lines ~215-216). RejectRisk uses `$addFields X = {$arrayElemAt: ["$X_ROW", 0]}` after a `$lookup` with `$limit 1`. It reproduces Oracle's scalar subquery or `(+)` join, where a missing code gives null. Cost: one sub-pipeline per input row, efficient only with an index on the foreign field (`let` + `$expr $eq` can use an index in recent MongoDB; verify with explain).

**Weak answer:** "No difference."

**Red flags:** Does not know `$unwind` drops rows.

**Follow-up questions:**
- Duplicate matches? (`$limit 1` hides them.)
- Alternative for tiny code tables? (Load the map once per request.)

### T109. "How do you translate Oracle `UNION` of WIP and live data into Mongo?"

**Strong answer:** Three patterns used here. 1) `$unionWith` (`AspEndtScheduleHandler`: `UWGE_POLICY_VERSIONS` plus `$unionWith WIP_UWGE_POLICY_VERSIONS`). 2) Two `$lookup` stages with `$ifNull` to take the first non-null (`AspEndtDocumentMainHandler`). 3) Two separate queries in Java and compare, to emulate Oracle's error when both exist (`requireNoConflict`, `distinctValueOrConflict`, which mimic ORA-01427). `SELECT DISTINCT` becomes `$group` (for example `UWPL_VI_POLICY_SCHEDULE_COVER`, numeric sort with `$toDouble(SORT_SEQ)`). `ROWNUM` becomes `$setWindowFields`/`$documentNumber` or `$limit 1`. `FROM DUAL` becomes a fallback DTO or `dualValue=1`. Oracle functions become REST calls. Duplicates are removed with `LinkedHashSet`.

**Weak answer:** "Use two queries and merge."

**Red flags:** Cannot name `$unionWith`.

### T110. "Sorting by `COV_SEQ_REF`: what is the trap?"

**Strong answer:** Jasper sorts by `cast(COV_SEQ_REF as decimal(15,2)) asc`. If the field is stored as a string, a plain sort puts "10" before "2". Most handlers use `$toDouble(COV_SEQ_REF)` (`PlineT12ParticularOfInsuredLandscapeAspHandler`, ASP insured/premium handlers). But `PlineT12ParticularOfInsuredLandscapeAmcHandler`, `PlineT12ParticularOfDiagnosisLandscapeHandler` and `...DiagnosisLandscapeAmcHandler` sort the raw field (inferred risk). Also null order: Oracle puts nulls last in ASC, Mongo puts them first. `$toDouble` of non-numeric text throws, like Oracle's cast (ORA-01722). Sponsor and DeleteMember lists have no ORDER BY in Jasper or in Java.

**Weak answer:** "Sort ascending."

**Red flags:** Never noticed string-versus-number.

### T118. "What does `PlineReportNames` do, exactly?"

**Strong answer:** A utility with `tag(Transactions, Class)` and `mainNameOf(Class)`. `mainNameOf` reads the class's `@Service` bean name, splits by `/`, takes the last segment and prefixes the previous segment unless the last already starts with it (ignoring underscores): `.../Template12/PolicyDocument` gives `Template12PolicyDocument`; `.../CharityReport/CharityReportDetail` gives `CharityReportDetail`. `tag` walks `Transactions > transaction > PlineTransactionDetails > header > reportTransaction > reportData` and sets `mainReportName` only where blank. Non-Plines responses are returned untouched. Services may set their own (ASP sets four constants). `PlineReportBlocks` adds `subReportName` (for example the RejectRisk header block). Added in `e74bc0d5c` (Oct 7) and `861f0666c` (Oct 8). The two elements are not in XSD v0.1.6.

**Weak answer:** "It names the report."

**Red flags:** Says it overwrites. Says the XSD has them.

- Why needed? (So the print engine can tie each `reportData` to a main and sub jrxml.)

### T119. "Which date format is on the wire and which does the XSD want?"

### T121. "Why do you get empty elements like `<slNo/>` in the XML?"

### T141. "What does the custom truststore do, and what breaks if the password is wrong?"
